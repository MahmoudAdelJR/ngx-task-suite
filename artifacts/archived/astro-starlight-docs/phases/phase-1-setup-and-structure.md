# Phase 1 Specification: Astro Starlight Site Setup & Infrastructure

## 🎯 Goal
Initialize the `docs` directory, configure Astro Starlight dependencies (`astro`, `@astrojs/starlight`), setup `astro.config.mjs`, create custom CSS for modern branding, and establish root site routing and sidebar structure.

## 📜 Work Items
1. Create `docs/package.json` with required Astro + Starlight dependencies and build scripts.
2. Install packages in `docs/` using `npm install`.
3. Create `docs/astro.config.mjs` configuring Starlight metadata, title, sidebar sections, and custom CSS.
4. Create `docs/src/content/config.ts` for Astro content collections schema (`docsSchema`).
5. Create `docs/src/styles/custom.css` for visual styling (theme colors, gradient text, badge styles, code block enhancements).
6. Create landing page `docs/src/content/docs/index.mdx` with hero cards, feature grids, and quick start CTA.

## 🏁 Phase Deliverable
Functional Astro Starlight framework in `docs/` ready for content pages.
